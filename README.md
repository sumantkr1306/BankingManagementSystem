🏦 Banking System (Java Console Application)

A simple Java-based console banking system that allows users to create multiple bank accounts and perform basic banking operations such as viewing account details, depositing money, withdrawing money, and updating address information.

This project is designed to demonstrate Object-Oriented Programming (OOP) concepts in Java such as classes, objects, constructors, encapsulation, and static members.

📌 Features

Create multiple bank accounts

Auto-generate unique Account IDs

Display account details

Deposit money

Withdraw money

Update account address

Track total number of transactions

Menu-driven console interface

🛠 Technologies Used

Java
